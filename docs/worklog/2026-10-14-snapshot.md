# Worklog snapshot — everything done up to 2026-10-14

What was built, in the order it landed on `main` (PRs #1–#31). Open work lives in [PENDING.md](../../PENDING.md), the current state in [LASTCONTEXT.md](../../LASTCONTEXT.md).

## Foundation (PRs #1–#24)

- Vite + TypeScript + Three.js scaffold, Vitest, ESLint, Prettier and GitHub Actions CI (lint, format, typecheck, tests, build, asset license check).
- Pure simulation in `src/sim` (no Three.js, enforced by ESLint and a test): movement, hitscan shooting, zombie chase and melee, waves, game over, deterministic RNG; fixed 60 Hz step with render interpolation. Game data in `data/game.json` behind a strict zod schema.
- Renderer: arena with obstacles, follow camera, lights, glTF loader with placeholder fallback, `AnimationController` state machine with clip names mapped in `data/characters.json`.
- Asset pipeline: `assets.toml`, `npm run check:assets` (CC0 / CC-BY only), generated README credits.
- HUD, game over, procedural Web Audio SFX, pause, best score in localStorage.
- RTS mode (selection, move orders, squad panel, `Y` to take direct control), the drone unit, inventory and weapon crates, camera zoom and orbit, one model per soldier, six enemy types with unlock waves, crouch / sprint / jump, gold and XP pickups, enemy health bars, hit flash and exploding gore.
- Stacked PRs merged into main through #24.

## Polish and publishing (PRs #25–#27)

- README rewritten with controls, renamed to **Zombie Horde Survivors**.
- Level-up perks (3 random squad-wide choices) and a between-wave shop (heal, revive, weapons, upgrades), data-driven in `game.json`; waves made tougher, intermission 8 s (PR #26).
- GitHub Pages deploy workflow, basic SEO (title, description, canonical, Open Graph / Twitter, JSON-LD, robots, sitemap, favicon, noscript), FPS counter on `F3` (PR #27).

## The big batch (PRs #28–#30, merged as #30)

- Fix: perk cards did not close the menu (a redraw-cache bug).
- Main menu with Start and a random 3D soldier floating on the right.
- Pause screen (Esc, P or I): bonuses and stats on the left, the squad on the right (health, level, XP, kills), up to four unit windows with 3D model and drag-and-drop inventories.
- Per-soldier XP and kill counter (the killer gets them); global XP still from the blue orbs.
- Soldiers start with a pistol (`squad.startWeapon`); the drone starts unarmed and needs a Drone gun; the equipped weapon can be unequipped; the rifle and the drone gun became crate and shop items.
- Mini boss every 3rd wave, growing with each appearance (health, damage, size), darker with red eyes.
- Radar: an Aliens-style motion tracker, light blue, centred on the squad.
- Arena grown to 80×80 with extra cover; zombies no longer get stuck on the corners of long obstacles.
- Dark lighting mode with a flashlight per soldier (`L`), normal lighting by default.
- XP per level doubled (200).
- Settings window (`O`): Low / Medium / High preset, shadows, shadow quality, resolution, blood and gibs, lighting, FPS counter, volume; saved in localStorage.
