# 2026-10-21 — Real CC0 surfaces and a 200 m Map 11

Branch `feat/helicopter` (not pushed, no PR). The user approved real CC0 textures ("te doy el ok") and asked to keep the procedural ones. Lint, format, typecheck, build, check:assets and the 48 tests pass; the new surfaces were checked by rendering a throw-away page in headless Chrome (not the full game).

- **Source:** ambientCG (every material there is CC0 1.0). Fourteen sets picked from thumbnails and downloaded (1K JPG zips) with a throw-away script into a scratch folder; only the colour, displacement and roughness maps were kept, shrunk to 512 px and re-saved as JPG (greyscale for height and roughness). 42 files, about 1.85 MB, in `public/textures/real/<name>_{color,height,rough}.jpg`. Each set is listed in `assets.toml` (author ambientCG, source page, CC0-1.0, path of the colour file) and in the README credits (`npm run credits`).
- **Walls:** `bricks` (Bricks059), `sandstone` (Bricks106A), `planks` (Planks037A), `concrete` (Concrete034), `plaster` (Plaster001), `darkrock` (Rock035), `darkmetal` (Metal046B). **Floors:** `paving` (PavingStones070), `roadreal` (Road007), `gravel` (Gravel023), `mossground` (Ground037), `clay` (Ground111), `marble` (Marble012), `tiles` (Tiles107). Assets are `pom_real_<name>`.
- **Code:** `src/render/realSurfaces.ts` (table of depth, tile size and material per set; `TextureLoader` with `import.meta.env.BASE_URL`); `src/sim/lab.ts` (`REAL_WALL_KINDS`, `REAL_FLOOR_KINDS`, `PomKind` now also `real_<name>`); `pom.ts` routes real kinds to the loaded maps and uses the same parallax shader (the normal is still derived from the height map, the downloaded normal maps were not used). The files load when a map first uses them, so they cost nothing at the first load; the textures fill in as they arrive.
- **Tile sizes** come from the metres in ambientCG's metadata where it was given (bricks 1.05 m, concrete 1.1, paving 1.15, gravel 1.5, moss 2.1, clay 2.8, road 7.5, tiles 1.0); the others are guesses (sandstone, planks, plaster, darkrock, darkmetal, marble). Concrete034 is a 110 x 55 cm photo, so it is stretched to a square. Tune `REAL` in `realSurfaces.ts`.
- **Map 11** is now 200 x 200 (`scripts/gen-map11.py`): a row of seven real walls and, behind it, seven real floor slabs in the north (z -76 and -90), and the seven walls again, turned, along the east edge (x 92).
- **Not done:** downloaded normal and AO maps are unused; no real sci-fi or alien sets (ambientCG has none that were checked); roughness-driven reflections need an environment map.
