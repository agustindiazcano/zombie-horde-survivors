# 2026-10-18 — Editor: marines, preview mode, unit inventory and stats, enemy spawners

On `feat/story-mode`. 48 tests and all checks pass; nothing seen in a browser.

- **Empty editor:** the editor no longer shows the default squad; only what the map places is drawn (Play still falls back to the default squad).
- **Preview mode (sandbox):** while editing, the sim runs with `state.sandbox`: no waves, no objectives, enemies stand still, no game over. **Y** drives the selected soldier (or the first one) and lets go again; WASD pans the camera when nobody is driven. Clicks edit the map, so a driven unit does not fire there. Any edit that changes units rebuilds the preview (control is lost).
- **R + right-drag:** hold R and drag with the right button to aim the selected units at the pointer (props in quarter turns); tapping R still turns one step. A right-drag on any item selects it and moves it without moving the camera.
- **Marines:** each soldier model is its own unit type, `marine1` to `marine4` (`data/units.json`, `model` = slot in `data/characters.json`); the Humans group of the catalog lists them. `soldier` stays as the type of the default squad. `isSquadUnit(config, type)` says whether a type belongs to the squad (human family or drone).
- **Per-unit changes in the map (`Loadout`):** a placed unit may carry `name`, `maxHealth`, `attributes`, `equipment` (hands, vest) and `backpack`. Soldiers get them in `createSquad` (`applyLoadout`; new `Soldier.baseHealth` and `name`; `maxHealthOf(state, config, unit)` is per unit now). Enemies get name, health and attributes, and what they carry (`backpack` plus equipment) drops in a crate where they die (`Zombie.loot`).
- **Editor windows:** **I** = inventory of the one selected unit (worn slots, backpack with remove, item list by tab: weapons, armor, medical, grenades, accessories; Equip / + Pack), **O** = stats (name, max health, attributes). Blank health goes back to the default. Both are one undo step per change (`src/unitDialogs.ts`).
- **Enemy spawners:** Units > Enemy spawners places `spawner:<enemy>` units. In the editor they show as that enemy (frozen) with a red ring; in play they are spawn points that make that enemy with the unit's changes (every enemy it spawns gets the same health and loot). They join the Game logic spawn points; I and O work on them.
- Not done: enemy attributes are stored but nothing reads them; spawned enemies from a spawner ignore wave health scaling when the spawner sets health; no per-enemy damage or speed edit; the squad bar still shows global max health; Play with no placed squad uses the default four marines/soldiers.
